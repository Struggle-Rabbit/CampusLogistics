## 通用说明

### 统一响应格式

**成功响应：**
```json
{
  "code": 200,
  "msg": "获取成功",
  "data": { ... }
}
```

**失败响应：**
```json
{
  "code": 500,
  "msg": "错误信息描述"
}
```

| 字段 | 类型 | 说明 |
|------|------|------|
| code | number | 200=成功，500=失败 |
| msg | string | 提示信息 |
| data | any | 业务数据（成功时返回） |

### 认证方式

除登录、注册、公开公告列表外，所有接口需要在请求头中携带 JWT Token：

```
Authorization: Bearer <your_access_token>
```

### 分页请求格式

所有分页列表接口的请求参数都包含以下两个字段：

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| currentPage | number | 是 | 当前页码，从1开始 |
| pageSize | number | 是 | 每页条数 |

### 分页响应格式

```json
{
  "code": 200,
  "msg": "获取成功",
  "data": {
    "list": [...],
    "total": 100,
    "currentPage": 1,
    "pageSize": 10
  }
}
```

### 删除接口说明

所有删除接口（`/del`）的请求体格式统一为 JSON Body：

```json
{
  "ids": ["id1", "id2", "id3"]
}
```

> 注意：用户管理、菜单管理、校区管理、楼栋管理、宿舍管理、水电费管理、公告管理的删除接口使用 `ids` 字段（数组）；角色管理使用 `id` 字段（数组）。

## 一、公共接口（无需登录）

### 1. 用户注册

```
POST /api/v1/register
```

**请求体（Body）：**

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| name | string | 是 | 姓名 |
| mobile | string | 是 | 手机号（需符合手机号格式） |
| password | string | 是 | 密码（8-20位） |
| userType | string | 是 | 用户类型：`00`-管理员、`01`-职工、`02`-学生 |

**请求示例：**
```json
{
  "name": "张三",
  "mobile": "13811111111",
  "password": "12345678",
  "userType": "02"
}
```

---

### 2. 用户登录

```
POST /api/v1/login
```

**请求体（Body）：**

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| account | string | 是 | 账号（手机号） |
| password | string | 是 | 密码 |

**请求示例：**
```json
{
  "account": "13811111111",
  "password": "12345678"
}
```

**响应 data：**

| 字段 | 类型 | 说明 |
|------|------|------|
| accessToken | string | 访问令牌 |
| refreshToken | string | 刷新令牌 |

**响应示例：**
```json
{
  "code": 200,
  "msg": "登录成功",
  "data": {
    "accessToken": "eyJhbGciOiJIUzI1NiIs...",
    "refreshToken": "eyJhbGciOiJIUzI1NiIs..."
  }
}
```

---

### 3. 公开公告列表（无需登录）

```
GET /api/v1/notice/public
```

**请求参数（Query）：** 同下方公告列表查询参数，可选

**响应 data：** 分页结构，`list` 为 `NoticePublicResult` 数组

| 字段 | 类型 | 说明 |
|------|------|------|
| id | string | 公告ID |
| title | string | 公告标题 |
| content | string | 公告内容 |
| notice_type | number | 公告类型：1-后勤通知 2-校园通知 3-紧急通知 |
| notice_type_name | string | 公告类型名称 |
| publish_time | string | 发布时间 |
| view_count | number | 浏览量 |
| attachments | string[] | 附件URL列表 |

### 2. 用户详情

```
GET /api/v1/user/detail
```
**权限标识：** `sys:user:detail`

**响应 data（UserInfoResult）：**

| 字段 | 类型 | 说明 |

| user_type | string | 用户类型 |

### 3. 删除用户

**权限标识：** `sys:user:del`

**请求体（Body）：**
